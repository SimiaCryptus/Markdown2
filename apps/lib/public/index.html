Quick start

One ES module, zero build step

Use marked.parse() as a synchronous drop-in, or mount() with sandboxHandlers() for the full interactive rich-media and permission-aware view. 

<div id="out"></div>
<script type="module">
  import { mount, sandboxHandlers } from 'https://md2.cognotik.com/lib/markdown2.js';

  const view = mount(document.querySelector('#out'), source, {
    handlers: sandboxHandlers(), // Mermaid, Graphviz, MathJax, Tartlet, Plotly, Vega-Lite, Maps, 3D, Calculators
  });
</script>
