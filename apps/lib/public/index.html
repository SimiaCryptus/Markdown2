        5. Handlers you write

        A handler turns bytes of one declared type into a view. These four took a few lines each: a palette drawn as SVG, a Unicode sparkline, an INI file as a table, and a shout. The last resource feeds the sparkline something that isn't a number. The handler throws, and the resource fails closed instead of breaking the page. 

        const md2 = new Marked({
  handlers: [{
    types: ['text/x-sparkline'],
    render: (bytes) => {
      const xs = new TextDecoder().decode(bytes).trim().split(/\s+/).map(Number);
      if (xs.some(Number.isNaN)) throw new Error('not a number');
      return `<p class="spark">${core.escapeHtml(toBars(xs))}</p>`;
    },
  }],
  hooks: { preprocess: (md) => md.replaceAll('{{today}}', new Date().toDateString()) },
  walkTokens: (token) => { counts[token.type]++; },
});

        7. Import it

        One ES module. Nothing to install; age encryption loads only when a key is used.

        <div id="out"></div>
<script type="module">
  import { marked, defaultCss } from 'https://md2.cognotik.com/lib/markdown2.js';

  // Optional: the default look for the Markdown2 styling tree.
  const sheet = new CSSStyleSheet();
  sheet.replaceSync(defaultCss);
  document.adoptedStyleSheets = [...document.adoptedStyleSheets, sheet];

  // Exactly like marked: a string in, escaped HTML out.
  document.querySelector('#out').innerHTML = marked.parse(source);
</script>

        The same names as marked: marked(), marked.parse, parseInline, use, setOptions, getDefaults, defaults, lexer, parser, walkTokens, Marked, Lexer, Parser, hooks, async and silent. Raw HTML is never passed through, so the output is safe for innerHTML.

        Synchronous, like marked. Everything that can be decoded without waiting is decoded: prose, tables, base64, JSON, CSV, SVG, WaveDrom. A gzip resource needs the asynchronous pipeline, so here it shows a fallback with requires-async. Locked resources stay locked.

            10. The live view API: mount()

            The playground above is this API and nothing more. Consent dialogs sit outside the document, where its styles cannot reach, and your app can answer them itself or skip them by supplying keys and origins. 

            const view = mount(el, source, {
  consent: (request) => defaultConsent(request),   // or your own policy, as in the playground
  allowOrigins: [],                                 // nothing trusted up front
  onChange: (state) => renderMyPanel(state),
});
await view.update(nextSource);
await view.unlock(id, { kind: 'passphrase', value: '…' });
await view.load(id, 'once');
await view.allowOrigin('https://www.openstreetmap.org');
view.setDocumentStyles(false);
await view.download(id, 'decoded');
await view.forget();

            13. What the library guarantees

            Section 4 checks several of these on every page load.

            • Escaped output. Raw HTML is never passed through; links are limited to safe schemes.
            • Nothing implicit. No key is used and nothing is fetched or framed without a grant from the user or your app.
            • Per resource. Grants are bound to one resource's payload and never inherited by nested resources.
            • No sniffing. The declared type picks the handler; a server's Content-Type is ignored.
            • Fail closed. Broken, locked or unknown resources show a labelled stub, never their bytes.
            • Inert images. SVG and WaveDrom are drawn through <img>, where scripts never run.
            • Contained styles. Document CSS cannot fetch, and in mount() it is scoped to its own document.
            • Safe saving. A document cannot pick an active file extension without consent.
