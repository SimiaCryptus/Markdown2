Charts: Plotly, Vega-Lite & Google Charts

Interactive data visualizations driven by plain JSON. Plotly and Vega-Lite run completely offline; Google Charts waits for your consent before contacting www.gstatic.com and shows its data as a table until then.

1. Plotly (2D & 3D interactive figures, offline)

application/vnd.plotly.v1+json ```plotly offline opaque-origin sandbox

Same JSON shape as Plotly.newPlot and Python's fig.to_json(). Hover for values, drag to zoom or rotate the 3D surface, and double-click to reset.

Live view

2. Vega-Lite (grammar of graphics, offline)

application/vnd.vegalite.v5+json ```vega-lite offline · vega-interpreter

Declarative charts using Vega-Lite v5 with the CSP-safe vega-interpreter (no eval). Inline data.values only — remote data URLs are blocked.

Live view

3. Google Charts (permission-gated remote view)

application/vnd.google.charts+json remote: https://www.gstatic.com table fallback

Google Charts loads its loader from www.gstatic.com, so it never draws until you allow it. Until then, the resource displays its data as a readable HTML table alongside a Load from www.gstatic.com… button.

Live view · click Load to grant network access
